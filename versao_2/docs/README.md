# Arquivista Digital Cetti v2

Ponto de entrada: `organizador_cetti_v2.py`.

A v2 usa Gemini, `cetti_core.py`, `cetti_interaction.py` e `cetti_logging.py`. Configure as variáveis em `config/.env`, usando `config/.env.example` como referência.

O launcher está em `scripts/executar_organizador_cetti.bat`. O log da v2 fica em `logs/cetti_monitor.log`.
