# Arquivista Digital Cetti v1

Ponto de entrada: `organizador_cetti.py`.

A v1 usa Gemini, monitora `CETTI_ROOT/0_ENTRADA` e organiza arquivos por advogado, cliente e tipo. Configure as credenciais e a raiz em `config/.env`, usando `config/.env.example` como referência.

O launcher está em `scripts/executar_organizador_cetti_v1.bat`.
